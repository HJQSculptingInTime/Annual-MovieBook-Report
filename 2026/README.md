## 三、书籍页 `2026.BookReview.html`

标题 `2026 书籍报告 · 14 本`，大标题「书籍报告」，小标题 `Book · Annual Review · 2026`，结束语「——写给这十四本」。

### 两种模式，一个开关

导语下面一行：`点击书脊 · 抽出 · 转身 · 翻开`，右边两个按钮 **立体书架 / 表格**（`#bkWrap[data-mode="shelf|detail"]`）。

| 模式 | 内容 |
|---|---|
| **立体书架**（默认） | 3D 书架一排 14 本书，只有书脊朝外；点哪一本就横过来翻到正面（两侧的书往两边让位），那本书抽出后浮起，卡片显示书名、作者、译者、出版社、出版年份、页数（电子书换成阅读时长）、阅读方式、读完日期。**书架模式的任何地方（卡片、悬停提示、类型环、三巨头卡）都不出现评分**；只有「表格」那一栏保留我打的星级 |
| **表格** | 原来的书单表格：书名 / 作者 / 出版社 / 年份 · ISBN / 星级（这一栏是原样式，保留） |

两种模式下面都挂着同一套图表（塞在书架 / 表格下方，`#detailView`）：
- **类型环**：环形统计图，本格 8、社会派 2、新本格 1、谍战 1、电影类 1、科幻 1
- **黄金推理三巨头**：阿加莎 4 本、奎因 2 本、卡尔 2 本，每人一张卡，卡内是迷你书脊
- **阅读方式**：购买实体书 6、校图书馆 4、电子书 3、其他 1

图表下方一句说明：**「一格就是一本书，同色即同类型」**。

### 书脊的两条尺寸规则

都写在页面脚本里（搜「立体书架」那段 IIFE，`H = 262 + …`）：

| 维度 | 规则 |
|---|---|
| **高** | 按「书名 + 作者名」的总字数：`H = 262 + (字数 − 最少字数) × 9.5`，现在最少 4 字（《风声》）→ 262px，最多 14 字（《阳光下的罪恶》）→ 357px。国籍前缀（[英] 等）不计入字数。故意把差距压窄，整排不至于参差 |
| **厚** | 按页数：`W = 20 + 页数 × 0.105`，夹在 24–70px。页数写在 `DATA.books` 的 `pg` 字段，标 `est` 的显示「约 N 页（估）」；《绝叫》427 页只用来算厚度（`card:false`），卡片上不出「页数」这一行 |

类型色同时决定书架与作者卡里书脚那条色条——同色即同类型（阿加莎、奎因、卡尔按豆瓣标签与作者归并成本格）。

### 点得开、合得上

- 书架上方有一层**不带 3D 变换的透明热区**（`#shelfHits`），按书脊实际矩形摆位置，边角那几本也点得到
- 键盘：`Enter` / `Space` 开合当前这本，`Esc` 合书，`←` / `→` 翻上一本 / 下一本
- 点书架空白处或书架底板也会合书

### 手机端

`≤ 760px` 整块书架和图表隐藏，**只留原来的书单表格**（横向滚动，不挤成一坨）和结束语。也就是说手机上看不出改过，还是老样子。

### 页底

结束语（`"——写给这十四本"` 那行，样式类 `tv-end`）→「书与电影写在同一份年里 · 回到 2026 观影报告」→ 三行小字：`2026.Douban286590474.xlsx` / `报告制作：胡嘉祺、GLM-5.4` / `© 2026 胡嘉祺`（`.src` / `.copy`）。影视页页底是同样的三行，两页的模型署名要一起改。

## 四、数字都在页面里（`const DATA`）

数据源是 `D:\Hujiaqi\DoubanExporter\output\Douban286590474_all（20261125）.xlsx`（「看过」+「读过」两张表）。原来有一个 `rebuild.py` 负责读表、重算、把数字写回页面；**这份脚本已经删掉**，现在两份 html 各内联一份 `const DATA = {…};`，正文里的数字也已经是写死的文字。

### `DATA` 里有什么

| 页 | 字段 |
|---|---|
| 两页都有 | `meta`（部数 / 起止 / 观影天数 / 短评字数 / 均分 / 五星数…）、`hours`、`ratings`、`countries`、`continents`、`decades`、`directors`、`series`、`f26`、`months26`、`months`、`tags` |
| 书籍页的 `books` | 每本一条：`t` 书名、`a` 作者（带 `[英]` / `[美]` / `[日]` 前缀）、`pub` 出版社、`py` 出版年、`isbn`、`tr` 译者、`g` 类型、`w` 阅读方式、`d` 读完日期、`pg` 页数、`est` 是否估的、`note` 估的依据、`dur` 阅读时长、`card` 是否在卡片上显示页数、`db` / `r` 豆瓣分与我的分（书架不显示，表格用） |

### 改数字时动哪里

- **书架 / 卡片 / 图表**：都从 `DATA.books` 读，改数组里那一条即可；数组顺序就是画面顺序（决定 NO.01 … NO.14 和左右位置）。
- **正文里的句子**（“138 部”“3.76”“36,686 字”这类）：已经是固定文字，要改就全文搜旧数字替换；封面大数字、`<title>`、页底统计行同理。没有脚本回填，改完按第七节的底线核对。
- **书单表格 `.bk-rows`**：静态 HTML，不是 JS 生成。加一本书要同时补两处——`DATA.books` 一条 + 表格里一行（书名 / 作者 / 出版社 / ISBN / 星级）。
- **页数 / 时长**：`pg` 写在 `DATA.books` 里。`w:'电子书'` 的书卡片上不出页数（纸书篇幅本来就是估的），只出 `dur` 阅读时长；时长没填就不显示这一行。纸书：`est:true` 显示「约 N 页（估）」（`note` 写估的依据），`card:false` 表示只拿去算书脊厚度、卡片不写（《绝叫》427 页就是这样），`dur` 填了会在页数下面多一行「阅读时长」。
- **时长是真实记录**：三本电子书的 `dur` 取自豆瓣短评里自己记的时间——《平面国》微信读书 `3:18`、《风声》微信读书 `6h15min`、《长夜难明》`5h9min`，页面上写成「3 小时 18 分」「6 小时 15 分」「5 小时 9 分」。这三条只进卡片，不进任何统计。
- **类型**：按豆瓣标签归并；阿加莎 / 奎因 / 卡尔一律算「本格推理」。

现状：14 本里三本电子书（《平面国》《风声》《长夜难明》）的 `pg` 仍标着 `est`——那个数只用来算书脊厚度，卡片上不显示，改卡片只显示上面那三个真实时长；《希腊棺材之谜》489 页，是整排最厚的一本（算式得 71px，触发 70px 上限封顶）。

### 别动的结构

- `#bkWrap` / `#shelfHits` / `.bk-rows` 这些容器和 id：JS 往里写书脊、热区和模式状态，删了就是空白。
- `DATA` 的字段名：脚本按名字读（`b.pg`、`b.card`、`b.a` 开头的国籍前缀等），改名会静默失效。
- 两页的 `const DATA = …;` 仍各自独立成行，改的时候整行替换最稳（不要拆成多行对象再手拼）。

## 七、改这两张页面时的底线

- **保持 UTF-8 带 BOM**，否则中文标签会乱码
- **别删 `.stage` / `#festGrid` / `#y26kpis` / `#bkWrap` / `#shelfHits` / `.bk-rows` 这些容器和 id**：JS 往里面写内容，删了就是空白
- **CSS 颜色走变量**（`var(--gold)` 之类），不要写死色值
- **内容块默认 `opacity:0`**，靠 `IntersectionObserver` 加 `.in` 显示；截图或打印前可临时覆盖 `.reveal{opacity:1!important;transform:none!important}`
- **别动 `2025\` 那边**：2025 是老版式，没有海报位、没有灯效、没有书籍页，互不影响
- 改完用 `node --check` 抽一遍脚本（两页都是），再把立体书架、表格、手机端各看一遍；动过数字的话，对着 xlsx 逐项核对
