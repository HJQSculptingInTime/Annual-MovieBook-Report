# 年度观影报告 · Annual Movie Report

两年观影记录，两份独立报告：**2025（87 部）** 与 **2026（135 部）**。
全部是本地静态页面，双击即开，不需要联网、不需要服务器。

---

## 一、文件目录

```
E:\Annual Movie Report\
├─ index.html                    ← 入口页：选年份（建议从这里进）
├─ README.md                     ← 本文件
├─ 2025\
│  └─ 2025.MovieReview.html      ← 2025 年度报告（87 部 · 平均 3.91）
└─ 2026\
   ├─ 2026观影报告.html           ← 2026 年度报告（135 部 · 平均 3.73）
   └─ 海报\
      └─ 说明.txt                ← 海报命名与放法
```

## 二、怎么打开、怎么跳年份

| 入口 | 说明 |
|---|---|
| `index.html` | 两张卡片，点哪张进哪一年 |
| 报告右上角 `2026 ▾` | **点击展开年份列表**，选 2025 / 2026 直接跳转 |
| 报告页脚 | 2025 底部「查看 2026 年度报告 →」；2026 底部「← 翻回 2025 年度报告」 |

右上角的下拉是**可展开列表**，以后加 2027、2028 只是往列表里多写一行，按钮和交互不用改。

> 注意：年份之间用的是**相对路径**（`../2025/…`、`../2026/…`），
> 所以 `2025\`、`2026\` 这两个文件夹必须保持同级，整包一起移动没问题，单独拖走一份会断链。

## 三、放 2026 的海报

把图片放进 `2026\海报\`，文件名用「《片名》海报」：

```
2026\海报\《可能的爱》海报.jpg
2026\海报\《苦涩的圣诞节》海报.jpg
2026\海报\《她回来的那天》海报.jpg
2026\海报\《巴黎夏日》海报.jpg
2026\海报\《罗斯》海报.jpg
```

- 支持 `.jpg` / `.jpeg` / `.png` / `.webp`，建议竖版 2:3（约 700×1050）
- 找不到图会自动显示占位封面（配色 + 竖排片名），**不会破图**
- 2025 那份是老版式，没有海报位，不需要放图

## 四、年末要补的 2026 数据

用记事本或 VS Code 打开 `2026\2026观影报告.html`，搜索：

```
===== 年末只需要改这里
```

下面是一个 `CONFIG` 对象，两处要改：

**1）`festivals` —— 三大电影节入选数**

```json
{ "name": "戛纳", "total": 6,
  "units": [ { "n": "主竞赛单元", "v": 3 },
             { "n": "导演双周", "v": 2 },
             { "n": "影评人周", "v": 1 } ] }
```

把 `null` 换成数字即可，页面会自动把「年末补录」标签换成「已确认」。

**2）`top5` —— 年度五佳**

第 1 名已定为《可能的爱》。其余四部改 `t`（片名）与 `quote`（一句话），
`runtime` 填分钟数（不填显示「—」）。片名要和豆瓣条目一致，才会自动带出导演、主演。

### 换了新表之后，数字会自己变吗？

会。报告不是手写数字，而是从豆瓣导出的 xlsx **算出来的**：

- 封面部数、评分、字数、星级分布
- 逐月柱状图、24 小时分布、年代分布
- 导演榜、出品地排行、系列进度
- 热词与标签
- 2026 新片专题的全部统计
- **连各章节导语里的数字都是自动填的**（如「希区柯克一个人贡献了 6 部」「美国 39 部（28.9%）」）

流程就是：**把新的 xlsx 发我 → 我跑一条命令重建 → 页面全部更新**。

下面这三样不会自动变，需要你确认或补：

| 项目 | 说明 |
|---|---|
| 电影节数字 | `CONFIG.festivals`，年末你给数，我填 |
| 年度五佳 | `CONFIG.top5`，年末你给片单，我填 |
| 海报图片 | 放进 `2026\海报\`，文件名 `《片名》海报.jpg` |

## 五、以后加 2027、2028

1. 新建文件夹 `2027\`，把新年度的报告放进去
2. 在 `index.html` 的 `.years` 里照抄一张卡片，改年份、部数、链接
3. 打开新报告，在右上角下拉里加上往年的入口
4. 顺手把 `2026\2026观影报告.html` 里的下拉补一行指向 2027

下拉里对应的代码只有一行，形如：

```html
<a role="menuitem" href="../2027/2027观影报告.html">2027</a>
```

## 六、统计口径（2026）

- 只统计豆瓣「看过」里的**电影长片**，共 135 部
- 剧集 5 部、短片 2 部只在封面提一句，不进正文统计
- 出品地按「国家 / 地区」栏第一项算，**不合并**日韩、不合并欧洲
- 导演只列看过 3 部及以上的，并排除只集中在单一 IP 系列的三位
  （《黑客帝国》《哈利·波特》《无间道》）
- 系列里《哈利·波特》前两部是 2025 年看的：算通关，片单只列今年 6 部
- 热词只取「手法」与「主题」两类，已剔除结尾、镜头、配乐这类通用词

## 七、部署到 GitHub Pages

整个文件夹就是站点根目录（`index.html` 在根），所有链接都是相对路径，可以直接发布。

**准备：** 仓库必须是 **Public**（免费账号的 Pages 只支持公开仓库）。

### 方式 A · 网页上传（不用命令行）

1. GitHub 右上角 **＋ → New repository**，名字随意，如 `annual-movie-report`，选 **Public**，创建
2. 进入仓库 → **Add file → Upload files**
3. 把 `index.html`、`README.md`、`.nojekyll`、`2025\`、`2026\` **一起拖进去**（拖文件夹会自动保留层级）
4. **Commit changes**
5. 仓库 **Settings → Pages** → Build and deployment
   - Source 选 **Deploy from a branch**
   - Branch 选 **main**，目录选 **/ (root)** → **Save**
6. 等 1–2 分钟，地址是：

```
https://<你的用户名>.github.io/annual-movie-report/
```

### 方式 B · Git 命令行

```bash
cd "E:\Annual Movie Report"
git init
git add .
git commit -m "2025-2026 annual movie report"
git branch -M main
git remote add origin https://github.com/<用户名>/annual-movie-report.git
git push -u origin main
```

推送后在 Settings → Pages 里按上面第 5 步开启即可。以后更新：`git add . && git commit -m "update" && git push`。

### 三个容易踩的坑

| 坑 | 说明 |
|---|---|
| **少了 `.nojekyll`** | GitHub Pages 默认用 Jekyll 构建，可能忽略某些文件。根目录的空文件 `.nojekyll` 已经在，别删。 |
| **中文文件名** | `2026观影报告.html`、`海报/` 这类文件名能正常访问（浏览器会自动转成 `%E8%A7%82...`），但复制链接时建议直接点站内链接，别手打。 |
| **大小写** | 服务器是 Linux，大小写敏感。改文件名时保持和链接里完全一致。 |

> 换成自定义域名：Settings → Pages → Custom domain 填域名，再在 DNS 里加一条 CNAME 指向 `<用户名>.github.io`。
